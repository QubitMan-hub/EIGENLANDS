# Docs

- `design/` – one spec per build phase: `phase1-core.md`, `phase2-village.md`, `phase3-4-circuit-multiplayer.md`.
- `WORLDGEN3.md` – the revision-3 world generator, the version boundary that keeps old worlds unchanged, and gameplay elevation. `WORLDGEN_OVERHAUL_REMAINING.md` tracks what is still unfinished.
- `HYDROLOGY.md`, `PLAYER_BUILDING.md`, `TEST_STORAGE.md`, `FORMATTING.md` – revision-2 hydrology, building, database-free tests and lint rules.
- `art/style-guide.md` – palette, pixel-art rules and the isometric projection.
- `legal/privacy.md` – what the game stores and how to delete it.
