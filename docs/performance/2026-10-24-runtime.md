That is approximately **13× less mean main-thread game-frame work**, **3.5× better median frame timing**, and **90% fewer rain streaks** in this run. Cold spikes still exist. These measurements do **not** establish a universal 10× FPS gain or performance on the friend's physical phone. Software GPU scheduling, initial shader compilation, device thermal limits and network latency differ from real hardware.

## Changes

- Roof rays intersect volume/roof bounds before retaining the original half-pixel sampling grid. Opaque building pixels use one buffered upload instead of per-pixel Canvas state changes. Six varied day/night roof and wall/cutaway fixtures remain pixel-identical. A single background building worker reuses that painter and transfers image bitmaps; nearby buildings are prepared before entry, nearest first. Unsupported/blocked workers use the ordinary optimized painter.
- A bounded background chunk worker warms the existing deterministic generator, climate and biome data ahead of travel. Rendering and solo authority share immutable base caches; edits/ownership stay in their normal authoritative layers. Worker failures unblock loading and fall back to normal generation. Cache entries use exact Float64 climate values and cloned terrain, with explicit size limits.
- Showing an already-cached chunk no longer marks the entire terrain window dirty. Invalidation is lazy/coalesced. Unchanged chunk snapshots skip full sprite rebuilding; object/structural snapshots still update collision immediately and remove stale records independently. Offscreen renderables are hidden and distant object views are released.
- Terrain has a small overscan margin. Its cached image follows the camera immediately between 15/24 Hz cosmetic paints. Actors, prediction, input, combat effects and telegraphs retain their own frame updates. Lighting uses a softer half-resolution render target and reuses unchanged ambient geometry.
- Auto chooses Economy for touch or limited CPU/memory devices. Economy uses a lower canvas resolution, readable integer scaling and simpler biome-matched materials; High retains the detailed terrain path. Both shader variants compile unused detail branches away. Native Settings expose Auto/Economy/High and Gentle/Full/Off weather, with validated saved preferences. Gentle rain is shorter, fainter and much sparser; storm tint/fog are calmer, and reduced motion suppresses lightning.
- Both client prediction and authoritative room simulation use real elapsed time with the same bounded fixed-step catch-up budget. A stalled frame no longer forces slow-motion walking/dashing through a capped render delta. Long suspensions never accumulate an unbounded replay backlog. Initial rendering/compilation happens while the login still reports entering the world.

## Validation and limits

Full workspace suite: **523 passed** (114 client, 249 server, 160 shared). Workspace typechecking and multiplayer/solo builds pass. Focused tests cover cache immutability, exact adopted worker data, stale worker queue cancellation/failure, snapshot collision/layer independence, clipped pixel buffers, terrain camera coverage, visual preferences and equal walking/dash travel under slow callbacks. Browser scripts cover worker pixel parity, shader opacity, native settings persistence, camera steering, attack/dash, solo/multiplayer controls and construction reloads. Final browser/integration evidence is recorded in [continuation notes](../CONTINUE_HERE.md).

Still needed: representative physical Android/iPhone measurements (FPS, memory and thermals), older-browser fallback playtests and large multiplayer encounter/network profiles. High graphics can remain GPU-limited on weak hardware; the game now starts those devices with a lighter preset rather than hiding combat or reducing creature populations.
