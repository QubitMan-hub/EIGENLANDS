# Complete isometric art pack

Give your game-building assistant this ZIP and MAJOR-OVERHAUL-PROMPT.md. Ask it to read the prompt and implement it in the actual game project.

The prompt requires a major visual overhaul, preserves the current character size, and enlarges houses and the surrounding world where necessary. It covers modular NPCs, realistic action timing, animals, mounted riders, statues and world integration.

## Contents

- characters/: 6 generated sheets covering both heroes, base bodies and earlier action/direction drafts, plus generation notes.
- customization/: 7 catalogs with 50 options each, except pants with 55. These are appearance references, not full animated equipment layers.
- animals/: 12 farm animals, 12 woodland animals, and 16 mounted-rider views across 3 sheets.
- environment/: 12 houses, 24 farmland designs, 16 tree assets and 24 rocks/ore assets across 4 sheets.
- MAJOR-OVERHAUL-PROMPT.md: complete implementation instructions.
- manifest.csv: file inventory and SHA-256 checksums.

All 20 previously delivered PNG sheets and their category notes are included. Earlier category ZIPs are not nested inside this ZIP; their files are included directly without duplication.

These are design references and generated drafts. Some sheets retain colored backgrounds, imperfect directions, inconsistent spacing or scale. Read the individual category notes. Cleanup, slicing, scale calibration, layer fitting and missing animation frames are part of the overhaul, not completed work in this pack.

The original uploaded character reference and game screenshot are no longer present in their temporary locations, so they could not be bundled. The generated sheets remain included; use the actual game project to establish its existing camera and scale. Supply the original references separately if available.
